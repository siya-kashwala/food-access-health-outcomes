# Food Access, Socioeconomic Barriers & Chronic Disease

🏆 1st Place — MPH Data Accelerator 2026

## Project Overview
This project examines how food insecurity and socioeconomic barriers relate to obesity, diabetes, and coronary heart disease prevalence across U.S. counties.

## Research Question
How does access to healthy food relate to obesity, diabetes, and cardiovascular disease prevalence?

## Data Sources
- CDC PLACES
- American Community Survey
- County Health Rankings

## Tools
- Python
- SQL
- Excel
- pandas
- matplotlib

## Variables Analyzed
- Food insecurity
- Poverty
- Household vehicle access
- Physical inactivity
- Food Environment Index
- Obesity
- Diabetes
- Coronary heart disease

## Analysis
County-level data from multiple public health datasets were cleaned, standardized, and merged using county FIPS codes. Exploratory analyses were used to examine relationships between socioeconomic barriers, food access, and chronic disease outcomes.
